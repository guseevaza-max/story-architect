# ADR-0005. AI Provider Layer: Router → Provider → Model

**Статус:** принято (требование заказчика) · **Дата:** 2026-09-15
**ТЗ:** п. 65, 66

## Решение
Приложение нигде не знает имени конкретной модели. Оно указывает **класс
задачи**, роутер выбирает модель из конфигурации:

| Класс | Назначение |
|---|---|
| `FAST` | извлечение, классификация, суммаризация, память |
| `STRONG` | Architect, Writer, работа со стилем |
| `REASONING` | Continuity, Impact Analysis, глубокий разбор |

Провайдер, адреса и модели задаются переменными окружения
(`AI_PROVIDER`, `AI_BASE_URL`, `AI_MODEL_FAST/STRONG/REASONING`).
Ключ читается единственным модулем `lib/ai/provider.ts` с директивой
`server-only` и никогда не покидает backend. Архитектурный тест проверяет,
что `AI_API_KEY` не упоминается больше нигде в коде.

## Дополнительно
Режим `AI_MOCK=true` проводит весь пайплайн на заглушках без ключа —
для разработки интерфейса и для демонстрации.

Стоимость каждого вызова считается по ценам из конфигурации и пишется
в `AiRun` (ТЗ п. 64, 76).
