# ADR-0001. Технологический стек

**Статус:** принято · **Дата:** 2026-09-15

## Решение
Next.js 15 (App Router) + TypeScript + Tailwind, backend на Route Handlers
и Server Actions того же приложения, PostgreSQL 16 + pgvector, Prisma, Zod.

## Обоснование
Отдельный FastAPI-сервис оправдан только тяжёлыми Python-библиотеками; в
объёме ТЗ их нет. Один рантайм — один деплой, одна модель типов от базы до
интерфейса. SQLite не используем даже в разработке: расхождение dev/prod
даёт баги, а pgvector нужен по ТЗ (п. 61, 67).

## Последствия
Тяжёлые вычисления в будущем выносятся отдельным воркером через очередь,
без переписывания приложения.
